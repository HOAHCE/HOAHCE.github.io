Tạo OAuth Client ID cho Google Calendar (làm một lần)

  1. Vào Google Cloud Console, tạo một project, rồi bật Google Calendar API trong mục APIs & Services → Library.
  2. Mục OAuth consent screen: chọn External, điền tên ứng dụng và email của bạn. Thêm email của bạn vào Test users. Bấm Publish app để chuyển sang Production, nếu không quyền đã cấp sẽ hết hạn sau 7 ngày. Chỉ mình bạn dùng nên không cần Google xác minh, chỉ hiện cảnh báo "chưa xác minh".
  3. Mục Credentials → Create credentials → OAuth client ID → Web application. Ở Authorized JavaScript origins thêm https://tranthaihoa.id.vn.
  4. Sao chép Client ID, dán vào dòng google_client_id ở đầu tệp _pages/lich.html, rồi đẩy lên main.
